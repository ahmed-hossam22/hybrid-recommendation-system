# Dataset Instructions

This project uses the **MovieLens 32M** dataset from GroupLens.

1. Download `ml-32m.zip` from https://grouplens.org/datasets/movielens/32m/.
2. Extract the archive.
3. Use these files in the notebook:
   - `ml-32m/movies.csv`
   - `ml-32m/ratings.csv`
4. In Google Colab, either upload the extracted CSV files to `/content/` or update the notebook paths to `/content/ml-32m/movies.csv` and `/content/ml-32m/ratings.csv`.

The dataset files are intentionally not stored in this repository because of their size. Keep local copies out of Git using `.gitignore`.
